# 캡처 가이드

"모든 화면"을 빠짐없이, 그리고 서비스끼리 비교할 수 있게 캡처하기 위한 기준입니다.

## 1. 메뉴마다 캡처할 화면 상태

해당되는 상태는 모두 캡처합니다. 없는 상태는 `analysis.md`의 화면 목록에 "해당 없음"으로 적습니다.

| # | 상태 | 설명 | 파일명 desc 예시 |
|---|---|---|---|
| 1 | 기본 목록 | 메뉴에 처음 들어왔을 때 화면 | `list-default` |
| 2 | 필터·검색 펼침 | 상세 검색, 필터 패널, 정렬 옵션을 연 상태 | `list-filter-open` |
| 3 | 탭·뷰 전환 | 탭, 목록/카드/캘린더 등 보기 방식별 화면 | `view-calendar` |
| 4 | 상세 | 항목 하나를 연 화면 | `detail` |
| 5 | 작성·등록 폼 | 새로 만들기 화면 전체 | `form-new` |
| 6 | 폼 옵션 펼침 | 폼 안의 드롭다운, 날짜 선택기, 선택 팝업(조직도 등) | `form-approver-picker` |
| 7 | 수정 폼 | 기존 항목 수정 화면이 작성 폼과 다를 때 | `form-edit` |
| 8 | 모달·팝업 | 확인창, 선택창, 미리보기 | `modal-preview` |
| 9 | 컨텍스트 메뉴 | 더보기(⋮), 우클릭, 일괄 작업 메뉴 | `menu-more` |
| 10 | 빈 상태 | 데이터가 없을 때 화면 (검색 결과 없음 포함) | `empty-search` |
| 11 | 안내·에러 | 유효성 검사 메시지, 권한 없음 안내 | `error-required` |
| 12 | 개인 설정 | 해당 메뉴의 사용자 설정 | `settings-user` |
| 13 | 관리자 설정 | 해당 메뉴의 관리자 설정 (권한이 있을 때) | `settings-admin` |
| 14 | 알림 | 해당 메뉴에서 발생하는 알림 표시 | `notification` |
| 15 | 도움말 | 툴팁, 가이드, 온보딩 | `help-tooltip` |

> 유효성 검사 메시지(#11)는 **빈 폼에서 저장 버튼을 누르면 즉시 저장될 위험이 있으므로** 직접 유도하지 않습니다. 필드 옆에 이미 보이는 안내만 캡처합니다.

## 2. 파일명 규칙

```
{NN}-{menu-slug}_{seq3}_{screen-desc}.png
```

| 부분 | 규칙 | 예시 |
|---|---|---|
| `NN` | 사이트맵의 대메뉴 번호 (2자리) | `02` |
| `menu-slug` | 대메뉴 영문 slug (소문자, 하이픈) | `approval` |
| `seq3` | 메뉴 안에서의 캡처 순번 (3자리) | `004` |
| `screen-desc` | 하위 메뉴 + 화면 상태 (영문 소문자, 하이픈) | `draft-form-expense` |

예: `02-approval_004_draft-form-expense.png`

- 하위 메뉴가 많은 경우 `screen-desc` 앞에 하위 메뉴 slug를 붙입니다. (`inbox-list-default`, `inbox-detail`)
- 한글, 공백, 특수문자는 쓰지 않습니다.
- 순번은 사용자가 화면을 따라가는 흐름(목록 → 상세 → 작성) 순서로 붙입니다.

## 3. 캡처 방법

- **해상도**: 브라우저 창을 1920×1080 기준으로 맞추고, 배율 100%에서 캡처합니다. 서비스마다 같은 조건으로 캡처해야 비교가 쉽습니다.
- **긴 페이지**: 전체 페이지 캡처를 우선 사용합니다. 지원되지 않으면 스크롤하며 나눠 캡처하고 `_p1`, `_p2`를 붙입니다. (`form-new_p1.png`)
- **모달·드롭다운**: 열린 상태가 잘리지 않게 캡처합니다.
- **마스킹**: 캡처 전 `privacy-masking.md`에 따라 개인정보를 가립니다.
- **새 창·새 탭**: 팝업 창으로 열리는 화면도 캡처하고, 분석 문서에 "새 창으로 열림"을 적습니다.

## 4. 함께 기록할 것

캡처할 때마다 `analysis.md`의 화면 목록에 한 줄씩 추가합니다.

| 항목 | 내용 |
|---|---|
| 파일명 | 캡처 파일명 |
| 화면명 | 화면 이름 (서비스에 표시된 이름 그대로) |
| 진입 경로 | `대메뉴 > 하위 메뉴 > 버튼` |
| URL 패턴 | 경로 부분만, ID는 `:id`로 일반화 (예: `/approval/doc/:id`) |
| 설명 | 이 화면에서 할 수 있는 일 한 줄 |
