# 안전 규칙 (읽기 전용 탐색)

벤치마크 대상은 **실제 운영 중인 계정**일 수 있습니다. 탐색 중 데이터가 바뀌거나 외부로 무언가 나가면 되돌릴 수 없으므로, 모든 프롬프트는 아래 규칙을 최우선으로 따릅니다.

## 1. 절대 하지 않는 동작

| 분류 | 금지 동작 예시 |
|---|---|
| 발송·공유 | 메일·메시지·알림 발송, 초대, 외부 공유 링크 생성, 공개 설정 |
| 결재·승인 | 상신, 승인, 반려, 회수, 전결, 대결 지정 |
| 생성·수정·삭제 | 저장, 등록, 임시저장, 수정 완료, 삭제, 휴지통 비우기, 이동, 일괄 처리 |
| 근태·업무 기록 | 출근·퇴근 체크, 휴가 신청, 일정 등록, 업무 상태 변경 |
| 계정·권한 | 사용자 추가·삭제, 권한 변경, 비밀번호 변경, 2단계 인증 설정, 로그아웃 |
| 결제 | 요금제 변경, 결제, 결제수단 등록, 해지 |
| 설정 | 회사·개인 설정의 "저장"/"적용" 버튼 |
| 연동 | 외부 서비스 연결, API 키 발급, 웹훅 등록 |
| 다운로드·업로드 | 대량 내보내기(엑셀 다운로드 등), 파일 업로드 |

## 2. 허용되는 동작

- 메뉴, 탭, 링크를 클릭해서 **화면 이동**
- 목록 항목을 클릭해서 **상세 화면 열람**
- 작성·등록·설정 화면을 **열기만** 하고, 저장하지 않고 닫기·취소·뒤로가기
- 드롭다운, 날짜 선택기, 필터, 정렬 옵션 **펼치기**
- 검색어 입력 후 검색 실행 (조회만 하는 동작)
- 모달·팝업 열고 **취소/닫기**로 닫기
- 마우스 오버로 툴팁 확인
- 개인정보 마스킹을 위해 **현재 브라우저 화면에서만** CSS/JS 적용 (서버에 저장되지 않음)

## 3. 애매한 상황 처리

1. 버튼 이름만 봐서는 즉시 실행되는지 화면이 열리는지 알 수 없으면 → **누르지 않고 사용자에게 묻는다.**
2. 확인 팝업("~하시겠습니까?")이 뜨면 → 항상 **취소**를 누른다.
3. 실수로 데이터가 바뀌었다고 의심되면 → **즉시 작업을 멈추고** 무엇을 눌렀는지 사용자에게 보고한다. 스스로 되돌리려고 하지 않는다.
4. 실행해야만 결과를 알 수 있는 기능은 실행하지 않고 분석 문서에 `[실행 안 함]`으로 표시한 뒤, 화면 문구·도움말을 근거로 동작을 추정한다.
5. 로그인이 풀리거나 추가 인증(OTP 등)을 요구하면 → 작업을 멈추고 사용자에게 다시 로그인해 달라고 요청한다.

## 4. 근거 태그

분석 문서와 기능 매트릭스의 모든 기능에 아래 태그 중 하나를 붙입니다.

| 태그 | 의미 |
|---|---|
| `[확인됨]` | 화면에서 직접 보고 확인함 |
| `[추정]` | 화면 문구, 도움말, UI 구조를 근거로 추정함 |
| `[실행 안 함]` | 안전 규칙 때문에 실행하지 않아 결과를 확인하지 못함 |
| `[접근 불가]` | 권한·요금제 제한으로 화면에 들어가지 못함 |
